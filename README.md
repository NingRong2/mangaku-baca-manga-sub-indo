## ✨ Kenapa Mangaku?

### 🚀 Loading Super Cepat
Halaman dan gambar komik di-cache di server global (CDN), jadi loading cepat dari mana saja di Indonesia. Teknologi server-side rendering membuat halaman langsung muncul tanpa menunggu JavaScript.

### 🌙 Dark Mode Default
Tampilan gelap yang nyaman untuk mata — cocok untuk marathon baca komik di malam hari. Desain clean tanpa pop-up atau iklan redirect yang mengganggu.

### 📱 Bisa di-Install di HP
[Mangaku](https://mangaku.website) adalah Progressive Web App (PWA) — tambahkan ke home screen HP dan gunakan seperti aplikasi native. Tidak perlu download dari Play Store.

### 🔍 Pencarian Cepat
Cari judul manga, manhwa, atau manhua dengan fitur pencarian real-time. Ketik beberapa huruf, hasilnya langsung muncul.

### 📂 50 Genre Lengkap
Dari **Action**, **Fantasy**, **Romance**, **Isekai**, hingga **Slice of Life** — filter komik berdasarkan genre favorit di [halaman genre](https://mangaku.website/genre).

### 📖 Riwayat Baca Otomatis
[Mangaku](https://mangaku.website) menyimpan riwayat baca secara otomatis di browser. Tidak perlu login atau buat akun — tinggal buka dan lanjut baca!

### ⭐ Bookmark Favorit
Tandai series yang kamu ikuti agar mudah ditemukan lagi. Semua tersimpan di browser tanpa perlu registrasi.

### 🔄 Update Harian
Chapter terbaru rilis setiap hari. Cek [halaman Update Terbaru](https://mangaku.website/update-terbaru) untuk melihat rilisan hari ini.

## 📱 Cara Menggunakan Mangaku

### Di HP (Mobile)

1. Buka **[mangaku.website](https://mangaku.website)** di browser HP (Chrome, Safari, dll)
2. Klik menu browser → **"Tambahkan ke Layar Utama"** atau **"Install App"**
3. Mangaku akan muncul di home screen seperti aplikasi biasa
4. Buka, cari komik favorit, dan mulai baca! 🎉

### Di PC / Laptop

1. Buka **[mangaku.website](https://mangaku.website)** di browser
2. Gunakan navigasi untuk browse [Manga](https://mangaku.website/manga), [Manhwa](https://mangaku.website/manhwa), atau [Manhua](https://mangaku.website/manhua)
3. Atau langsung cek [Update Terbaru](https://mangaku.website/update-terbaru)
4. Klik judul komik → pilih chapter → mulai baca!
